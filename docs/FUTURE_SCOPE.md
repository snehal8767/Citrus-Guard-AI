# Future Scope

1. **Real model.** Train on pathologist-labelled Vidarbha citrus imagery; swap in via the `Predictor` protocol.
2. **Marathi UI + voice.** i18n plus a voice-command layer over the existing command parser (intents already exist).
3. **Hardware loop.** MQTT ingestion for soil nodes; drone waypoint missions writing real `Scan` rows.
4. **Upload-to-zone linkage.** Let an analyzed photo attach to a zone and enter history.
5. **Multitenancy.** Many orchards, farmer cooperatives, per-farm data isolation, Postgres.
6. **Agronomist review queue.** Verified alerts escalated to experts; their notes feed retraining labels.
7. **Weather fusion.** IMD/local forecast API blended into the environment-stress factor.
8. **Offline PWA.** Capture in the field, sync when back in coverage.
9. **PDF reports + WhatsApp alerts.** Meet farmers where they already are.
10. **Calibration dashboard.** Back-test risk weights against outbreak logs; version the formula.
